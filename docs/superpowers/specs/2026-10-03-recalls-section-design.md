# مواصفة قسم «ريكولات» — 2026-10-03

## الهدف
قسم قراءة فقط يعرض أسئلة الريكالات (الأسئلة التي وردت في اختبارات سابقة) **كما وردت حرفياً** دون أي توحيد أو تصحيح للنص الأصلي، مع «قراءة علمية» موثقة لكل سؤال: الجواب المُرجَّح + تبرير قصير + مصادر علمية عليا مباشرة، وأزرار بحث Google/PubMed بنتائج جاهزة.

## المبادئ الحاكمة
1. **الأمانة الأرشيفية:** النص الخام لا يُعدَّل أبداً (بما فيه أخطاء الإملاء). التصحيح يحدث فقط في طبقة «القراءة العلمية».
2. **الموثوقية أولاً:** لا تبرير بلا رابط مصدر وجُد فعلاً (قاعدة «المصدر أولاً»). الروابط المدفوعة (UpToDate) ممنوعة.
3. **نشر الكل:** السجلات «غير المحسومة» تُنشر أيضاً بحالة صريحة + زر بحث جاهز بدل التبرير.
4. **قراءة فقط:** لا إجابات تفاعلية، لا حفظ في localStorage، خارج Readiness Score وسجل الجلسات نهائياً.

## هيكل البيانات (`data/recalls.json`)
مصفوفة سجلات:
```
{
  id, source_file, page, type,             // type: handwritten | printed
  raw_text, raw_options[], raw_answers,    // حرفي كما ورد (قد يكون فارغاً)
  extraction_confidence (0-10), completeness (0-10),
  topic,                                   // تصنيف طبي مختصر بالإنجليزية
  verdict: {
    state: confirmed | probable | unresolved,
    answer,                                // للسجلات المحسومة فقط
    justification,                         // 2–4 أسطر عربية
    sources: [ {label, url} ]              // StatPearls/NCBI, WikEM, Merck, LITFL, AHA/ERC/WHO/CDC, PubMed فقط
  },
  queries: { google, pubmed }              // روابط بحث مسبقة الصياغة (google.com/search?q=...&udm=14)
}
```

## خط الأنابيب
1. تحويل ملفات الحالة صفر (phase0-extraction) إلى سجلات مهيكلة (parsed_records.json).
2. تفسير دفعات بوكلاء مع بحث ويب: تصنيف الموضوع، تحرّي الجواب، كتابة التبرير بعد إيجاد المصدر. الدفعة الأولى: 214 سؤالاً MCQ-like (DOC-20240802 + M1 + recallAug)، ثم بقية الأسطر المفردة لاحقاً.
3. فحص آلي: كل URL من النطاقات المسموحة، كل state ضمن المجموعة، كل سجل له queries.google.
4. مراجعة بشرية (المستخدم) لعينة عشوائية.

## الواجهة
- **الهوم:** كرت في القسم الأخير «📜 ريكولات — أسئلة وردت في اختبارات سابقة» + عدّاد السجلات.
- **#recalls:** قائمة قراءة واحدة، مربع بحث نصي + شرائح فلترة حسب حالة الثقة (الكل/مؤكَّد/مُرجَّح/غير محسوم).
- **البطاقة (علمي أولاً + طي الأرشيف):**
  - الموضوع + شارة الحالة + أجوبة الريكول الأصلية (سطر «متداول بين الطلاب»).
  - التبرير العلمي.
  - أزرار: المصدر • تحقق في Google • PubMed — تفتح النتائج جاهزة.
  - قسم قابل للطي «كما ورد في الريكالات»: النص الحرفي + شارات (خط يد/مطبوع، الملف، الصفحة، ثقة الاستخراج).
- **لمسة جمالية:** الخيارات والأجوبة الخام (فقط) تُعرض بخط يشبه خط اليد؛ بقية السؤال والشرح بالخط العادي.

## خارج النطاق (بعد الدفعة الأولى)
أسطر الريكول المفردة (~420 سجلاً)، أي تفاعل تقييمي، أي تعديل على نص الحالة صفر.
